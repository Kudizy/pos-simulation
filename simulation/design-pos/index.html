Activation facture normalisée

Afin de pouvoir émettre votre facture normalisée, vous devrez faire valider vos informations par la DGI (Direction Générale des Impôts). Cette demande de validation se déroulera en 4 (quatre) étapes.

1. Demande d’activationÀ faire
2. Validation de la demandeCode email
3. Approbation (code NIM)DGI
4. Finalisation (jeton)Code email

Si vous possédez déjà un jeton valide dans votre compte Sygmef déjà configuré une fois sur Kudizy, vous pouvez poursuivre la configuration manuellement en cliquant ici.

FN 1/4 Demande2 Validation3 NIM4 Jeton

Étape 1 sur 4 · Demande d’activation

Veuillez remplir les informations ci-dessous pour l’activation.

Information sur le contribuable

Sélectionnez « Oui » si vous êtes un particulier et « Non » si vous représentez une entreprise.
La configuration pour les particuliers n’est pas disponible pour le moment.
Entrez votre Identifiant Fiscal Unique (IFU) qui vous a été délivré par la Direction Générale des Impôts (DGI).
Entrez l’adresse du siège social de votre entreprise (ex: C/2230, Maison Dossou Charles).

Information sur le secteur d’activité

Entrez l’activité principale de votre entreprise (ex: alimentation et nutrition pour enfants).
Si vous n’avez pas d’activité secondaire, entrez votre activité principale.

Informations sur le point de vente

Entrez le nom de votre point de vente ou de votre entreprise (ex: Kids Food Shop).
Donnez plus de précisions sur l’adresse de votre point de vente (ex: rue des oliviers, C/2230, Maison Dossou Charles à coté du marché Dantokpa).
Décrivez l’emplacement de votre point de vente (ex: magasin situé au cœur de Cotonou, à proximité du marché Dantokpa).
Entrez le même numéro de téléphone si vous n’en avez pas d’autre.

Informations sur le demandeur

Entrez le nom et les prénoms de la personne qui fait la demande d’activation d’e-MECef.
Entrez le titre du demandeur (ex: Responsable de la gestion des opérations).
Entrez le lieu de la demande (ex: Cotonou, Bénin).
FN 1 Demande2/4 Validation3 NIM4 Jeton

Étape 2 sur 4 (Validation de votre demande)

Un email a été envoyé à l’adresse associée à votre IFU par la DGI contenant un code de validation. Veuillez renseigner ce code pour valider votre demande.

Si vous ne l’avez pas eu dans votre boîte de réception, prière consulter votre dossier SPAM.

FN 1 Demande2 Validation3/4 NIM4 Jeton

Étape 3 sur 4 (Approbation de votre demande)

Statut DGIApprouvée

Félicitations, votre demande a été approuvée. Un mail vous a été envoyé par la DGI contenant votre code NIM. Veuillez renseigner ce code NIM afin que Kudizy puisse procéder à la configuration de votre compte.

Si encore en traitement : votre demande peut prendre jusqu’à 72 heures. Merci de patienter et de vérifier régulièrement votre boîte mail.

FN 1 Demande2 Validation3 NIM4/4 Jeton

Étape 4 sur 4 (Finalisation de votre demande)

Un mail vous a été envoyé par la DGI contenant votre code de validation. Veuillez renseigner ce code pour finaliser la configuration de votre compte.

Si vous ne l’avez pas eu dans votre boîte de réception, prière consulter votre dossier SPAM.
