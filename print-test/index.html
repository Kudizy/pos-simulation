Installer Kudizy Print Connector

Ce petit programme permet à la caisse d'imprimer sur ce PC. Version à télécharger : 1.0.3. Si une ancienne version tourne déjà, quittez-la (icône près de l'horloge → Quitter) avant d'ouvrir le nouveau fichier.

Télécharger le Print Connector 1.0.3 (Windows)

  1. Si le navigateur signale un fichier « rarement téléchargé », choisissez Conserver.
  2. Ouvrez le fichier téléchargé.
  3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  4. L'icône Kudizy apparaît près de l'horloge. Cette page la détecte toute seule, sans recharger.

Le Print Connector fonctionne sur PC Windows. Sur téléphone ou tablette Android, ouvrez cette page dans l'application Kudizy.

Connecteur trop ancien. Téléchargez la version 1.0.3 (bouton ci-dessus ou section 1), quittez l'ancienne icône, puis relancez le nouveau fichier. À partir de 1.0.3 : accents corrects et ticket qui ne déborde plus sur le simulateur Docker.

2. Associer cette page au connecteur

Le code à 6 chiffres s'affiche en cliquant sur l'icône Kudizy près de l'horloge Windows.

3. Choisir l'imprimante

Simulateur Docker (page des tickets : http://localhost:8080)

Les titres receipt… sont les noms de fichiers du simulateur : ce n'est pas le numéro Kudizy. Ouvrez le ticket le plus récent (en haut) : le vrai numéro est la ligne Ticket n° … dans le contenu (avec « MINI MARCHÉ DU PLATEAU »).

Vider la liste (pas de bouton dans l'interface) — PowerShell :

docker exec imprimante-virtuelle sh -c "rm -f /home/escpos-emu/web/receipts/* /home/escpos-emu/web/receipt_list.csv"

Puis rechargez localhost:8080. Pour repartir de zéro :

docker rm -f imprimante-virtuelle
docker run -d --name imprimante-virtuelle -p 9100:9100 -p 8080:80 gilbertfl/escpos-netprinter:3.2
